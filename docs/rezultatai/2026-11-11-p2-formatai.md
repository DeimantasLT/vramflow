## Chromos PSNR prieš FFmpeg (`tests/perf/chroma_psnr.py`, ctest `chroma_psnr_*`)

Mūsų 4:2:2 10 bitų prieš `ffmpeg -pix_fmt yuv422p10le` (pikas 1023), 3 kadrai:

| Šaltinis (1080p50) | Kadro chroma U / V, dB | Y | Lauko chroma (senas kelias) U / V, dB |
|---|---|---|---|
| zonų plokštė (`kx2=ky2=10`) | 64,7 / 64,7 | identiškas (inf) | 54,7 / 54,6 |
| generatoriaus klipas (`clip --format 1080p50`) | 60,9 / 60,3 | identiškas (inf) | 47,3 / 46,7 |

Ribos: kadro chroma ≥ 60 dB, lauko < 56 dB. 1080p25 — tie patys skaičiai; 720p50: zonų plokštė 64,4 / 64,4 (lauko
53,4 / 53,1), klipas 61,0 / 60,1 (lauko 47,4 / 46,5). Pastaba: klipo atsarga maža
(0,3 dB) — FFmpeg etalonas naudoja bicubic interpoliaciją, mūsų formulė tiesinė (3:1); aukštesnio dažnio zonų plokštė
(`kx2=20`) duoda 57,7 dB, todėl testo turinys parinktas vidutinės dažnių juostos.

„Prieš“ — `e9349d3` (prieš P2) binarinis failas, „po“ — galutinis. 3 bėgimai, lentelėje — p50 mediana (bėgimų intervalas).

| 1080p50 | G | 4,784 (1,851–5,439) | 10,879 | 55,3 (10 × 5,53) | 0 praradimų |
| 1080p50 | C | 3,375 (3,375) | 4,391 | — | N = 8 virš CPU talpos (~830 iš 1750 grain'ų) |

Išvados:
- 1080i50 nepablogėjo daugiau nei 3 % (G +1,6 %, C +2,1 % — vienas histogramos žingsnis).
- Progresyvus grain'as — 2× daugiau duomenų: C variantas N = 8 su 1080p50 viršija CPU talpą (gen + logo tame pačiame
  CPU), 1080p25 — ties riba. G variantas visais formatais be praradimų.
- 1080p25 G p50 10,9 ms stabiliai (visi 3 bėgimai) — daugiau nei 1080p50 G, nors darbo kiekis grain'ui tas pats.
  Tikėtina GPU galios būsena tarp 40 ms tick'ų (WSL2); nepatikrinta — reikia kernel'io laiko be sync (nsys) arba
  fiksuotų taktų.
- SM % nematuota (nebuvo nsys / nvidia-smi zondo šiame bėgime).
